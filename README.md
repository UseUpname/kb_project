# kb_project
# 소상공인 금융 위험신호 분석 프로젝트

## 1. 프로젝트 소개

소상공인은 매출이 줄거나 상권이 약해질 때 예금이 줄고 대출이 늘어나는 등 금융 이용 방식에도 변화가 나타날 수 있습니다.
이 프로젝트는 소상공인의 **지역·업종별 매출 변화와 금융상품 이용현황을 함께 분석**해, 어떤 고객군에서 위험신호가 나타나는지 확인하는 것을 목표로 합니다.
은행원이 소상공인 고객을 상담하거나 사후관리할 때 참고할 수 있는 간단한 분석 도구를 만드는 것이 최종 목적입니다.

---

## 2. 주요 질문

이 프로젝트는 다음 질문에 답하려고 합니다.

- 어떤 지역과 업종에서 매출이 감소하고 있는가?
- 매출이 줄어든 소상공인은 예금과 대출 이용이 어떻게 달라지는가?
- 어떤 고객군에서 위험신호가 더 자주 나타나는가?
- 은행원이 추가로 확인해야 할 고객은 누구인가?

---

## 3. 사용 데이터

### 실제 공개 데이터
- 지역·업종별 매출 데이터

### 가상 데이터
실제 개인의 금융거래 정보는 공개되지 않기 때문에 아래 항목은 프로젝트용 가상 데이터로 만듭니다.

- 4번 financial product + 대출 가상 데이터, 고객 업종, csv 파일 내의 행정동 코드, 매출 항목

---

## 4. 주요 기능

### 1) 지역·업종별 매출 분석
지역과 업종별로 매출이 얼마나 늘거나 줄었는지 확인합니다.

### 2) 금융상품 이용 변화 분석
예금잔액, 대출잔액 등의 변화를 비교해 고객의 금융 이용 패턴을 확인합니다.

### 3) 위험신호 탐지
예를 들어 아래와 같은 경우를 위험신호로 볼 수 있습니다.

- 매출 감소
- 대출잔액 증가
- 예금잔액 감소
- 사업자 평가 악화

여러 신호가 동시에 나타나는 고객군을 우선 점검 대상으로 확인합니다.

## 4) AI 요약
분석 결과를 AI가 쉽게 읽을 수 있는 문장으로 정리하고, 은행원이 추가로 확인할 사항을 제안합니다.

---

## 5. 사용 기술

- SQL: 지역·업종·고객 유형별 데이터 조회 및 집계
- Python / Pandas: 매출 증감률, 예금·대출 변화, 위험신호 계산
- SQLite: 분석에 사용하는 데이터 저장
- n8n / AI: 주요 분석 결과 요약 및 추가 확인사항 제안

---

## 6. 분석 흐름

공공데이터 및 가상 금융데이터 수집  
→ 데이터 정리  
→ SQL로 지역/업종/상품별 이용현황 집계  
→ pandas로 매출 감소군 vs 비감소군 비교
→ Python으로 추가 확인 후보 rule 적용
→ 위험 고객군 확인  
→ AI가 결과 요약, 은행원 용 브리핑으로 변환 

---
## 7. 기대 활용

이 프로젝트는 실제 대출 승인 여부를 결정하는 시스템이 아닙니다.

대신 은행원이 소상공인 고객을 상담하거나 관리할 때

- 최근 매출이 줄고 있는지
- 대출 의존도가 높아지고 있는지
- 추가 확인이 필요한 위험신호가 있는지

빠르게 파악할 수 있는 **참고자료**를 만드는 것을 목표로 합니다.

---

## 8. 한계 사항

시간 문제로 모든 상황에서 구현되도록 DB를 형성하지는 못했음. 

---
## 9. 데이터 사용 시 주의사항

실제 공개 데이터와 프로젝트용 가상 데이터를 함께 사용합니다.

가상 데이터는 실제 고객의 금융정보가 아니며, 분석 실습을 위해 만든 데이터입니다.

또한 위험신호는 고객의 부실 여부를 확정하는 기준이 아니라, 추가 확인이 필요한 대상을 찾기 위한 참고지표로 사용합니다.
