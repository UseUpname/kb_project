# kb_project
# 소상공인 금융 위험신호 분석 프로젝트

## 1. 프로젝트 소개

소상공인은 매출이 줄거나 상권이 약해질 때 예금이 줄고 대출이 늘어나는 등 금융 이용 방식에도 변화가 나타날 수 있습니다.
이 프로젝트는 소상공인의 **지역·업종별 매출 변화와 금융상품 이용현황을 함께 분석**해, 어떤 고객군에서 위험신호가 나타나는지 확인하는 것을 목표로 합니다.
은행원이 소상공인 고객을 상담하거나 사후관리할 때 참고할 수 있는 간단한 분석 도구를 만드는 것이 최종 목적입니다.

---

## 2. 주요 질문

이 프로젝트는 다음 질문에 답하려고 합니다.

- 어떤 지역과 업종에서 매출이 감소하고 있는가?
- 매출이 줄어든 소상공인은 예금과 대출 이용이 어떻게 달라지는가?
- 어떤 고객군에서 위험신호가 더 자주 나타나는가?
- 은행원이 추가로 확인해야 할 고객은 누구인가?

---

## 3. 사용 데이터

# 실제 공개 데이터
- 소상공인 상권·업종 정보
- 지역·업종별 매출 데이터
- 개인사업자 평가 및 위험 관련 데이터

# 가상 데이터
실제 개인의 금융거래 정보는 공개되지 않기 때문에 아래 항목은 프로젝트용 가상 데이터로 만듭니다.

- 예금 잔액
- 대출 잔액
- 대출 종류
- 금리
- 연체 여부
- 기간별 금융 이용 변화

## 4. 주요 기능

# 1) 지역·업종별 매출 분석
지역과 업종별로 매출이 얼마나 늘거나 줄었는지 확인합니다.

# 2) 금융상품 이용 변화 분석
예금잔액, 대출잔액 등의 변화를 비교해 고객의 금융 이용 패턴을 확인합니다.

# 3) 위험신호 탐지
예를 들어 아래와 같은 경우를 위험신호로 볼 수 있습니다.

- 매출 감소
- 대출잔액 증가
- 예금잔액 감소
- 사업자 평가 악화

여러 신호가 동시에 나타나는 고객군을 우선 점검 대상으로 확인합니다.

# 4) AI 요약
분석 결과를 AI가 쉽게 읽을 수 있는 문장으로 정리하고, 은행원이 추가로 확인할 사항을 제안합니다.

## 7. 기대 활용

이 프로젝트는 실제 대출 승인 여부를 결정하는 시스템이 아닙니다.

대신 은행원이 소상공인 고객을 상담하거나 관리할 때

- 최근 매출이 줄고 있는지
- 대출 의존도가 높아지고 있는지
- 추가 확인이 필요한 위험신호가 있는지

빠르게 파악할 수 있는 **참고자료**를 만드는 것을 목표로 합니다.

---

## 8. 데이터 사용 시 주의사항

실제 공개 데이터와 프로젝트용 가상 데이터를 함께 사용합니다.

가상 데이터는 실제 고객의 금융정보가 아니며, 분석 실습을 위해 만든 데이터입니다.

또한 위험신호는 고객의 부실 여부를 확정하는 기준이 아니라, 추가 확인이 필요한 대상을 찾기 위한 참고지표로 사용합니다.

## 9. 담당자별 분석 결과: 3번 SQL 상권·대출 분석 (`market_loan_analysis.sql`)

### 1) 분석 목적
- 서울시 424개 행정동 및 11개 업종 상권의 3개년(2023~2025년 12분기) 매출 시계열 변화(YoY, QoQ)와 당행 소상공인 고객(2,000명)의 대출 현황을 결합 분석합니다.
- 상권 매출이 위축되면서 대출 잔액이 집중되어 있는 **잠재적 위험 상권**을 조기에 식별하여, 은행원이 소상공인 상담 및 사후관리 시 우선 확인해야 할 참고 지표를 제공합니다.

### 2) 분석 방법 및 데이터 정합성 원칙
- **고객 단위 대출잔액 중복 합산 방지**: 원천 금융상품 테이블은 고객 1인당 3건의 금융상품 가입 정보가 비정규화 결합되어 있어, 단순 `SUM(대출_잔액)` 시 3배 왜곡이 발생합니다. 이에 고객 레벨 정규화 뷰(`VW_CUSTOMER_LOAN_SUMMARY`)를 구축해 실제 대출잔액(186.3억 원)을 정밀하게 산출했습니다.
- **유일 키 기반 결합**: 서울시 내 동일 행정동명(예: 강남구 신사동 vs 관악구 신사동) 중복 문제를 방지하기 위해 8자리 `행정동_코드`와 `업종(업종군)`을 복합 조인 키(`행정동코드_업종`)로 설정했습니다.
- **시계열 지표 및 뷰 체계화**:
  1. `VW_CUSTOMER_LOAN_SUMMARY`: 고객별 고유 대출/매출 속성 뷰
  2. `VW_MARKET_SALES_TREND`: 상권별 최신 매출(20254), YoY/QoQ 증감률, 매출 추세 분류 뷰
  3. `VW_MARKET_LOAN_ANALYSIS`: 상권 매출 지표 + 당행 대출잔액 결합 종합 분석 뷰 (1,563개 상권)
  4. `VW_HIGH_RISK_MARKET_LOAN`: 상권 매출 급감 및 대출 집중 고위험 상권 추출 뷰

### 3) 핵심 분석 결과
1. **업종별 대출잔액 1위는 음식·음료 (57.7억 원, 평균 YoY -0.98%)**:
   - `음식·음료` 업종은 상권 평균 매출이 역성장 중임에도 총 57.7억 원(운전자금 34.1억 원)으로 대출잔액 규모가 가장 컸습니다.
   - 이어 `식료품·편의소매`(50.7억 원), `전자기기·수리`(37.9억 원) 순으로 대출이 집중되어 있습니다.
2. **지속감소 상권에 총 37.8억 원 대출 집중**:
   - 상권 매출이 전년 동기 및 전기 대비 모두 감소한 '지속감소' 상권(496개)에 347명의 소상공인이 총 37.8억 원의 대출을 보유하고 있으며, 특히 신용대출(29.1%)과 운전자금대출(53.0%) 비중이 높아 모니터링이 시급합니다.
3. **은행원 우선 확인 고위험 상권 13곳 도출**:
   - 상권 매출 YoY -10% 이하 급감 + 대출잔액 3,000만 원 이상 집중 상권 13곳을 추출했습니다.
   - **대표 취약 상권**: 
     - `방배1동 미용·뷰티`: 상권 YoY -10.3%, QoQ -31.2%, 고객 자체 매출증감률 -52.4%, 신용대출 3,200만 원 보유.
     - `황학동 가구·인테리어`: 상권 YoY -19.9%, QoQ -11.7%, 고객 자체 매출증감률 -15.0%, 대출잔액 5,230만 원 (운전자금 4,130만 원).
     - `신도림동 음식·음료`: 상권 YoY -18.4%, 고객 자체 매출증감률 -15.3%, 대출잔액 3,680만 원.
